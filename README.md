# 主日學教案設計 Skill

天主教主日學教案產生器，為 [OpenCode](https://opencode.ai) 而寫。

給三個學習目標，產出一份 60 分鐘、初小（6-8 歲）的繁體中文教案。

## 產出內容

| 部分 | 分鐘 | 內容 |
| --- | --- | --- |
| 開始祈禱 | 4 | 十字聖號、點名、禱文 |
| 引起動機 | 8 | 三個遊戲方案供選擇（動覺／零材料／概念） |
| 發展一：認識 | 14 | 看前任務、影片、講述、提問、重複接力 |
| 發展二：明白 | 10 | 先生活、後道理，只有一個道理 |
| 發展三：實踐 | 10 | 情境、示範、一個具體決定 |
| 綜合 | 6 | 三問回顧、金句齊唸 |
| 生活實踐 | 5 | 本週一件行動、金句卡 |
| 結束祈禱 | 3 | 與喜訊緊扣 |

## 設計特點

- **教理中心教案骨架**：以「認識（知識）→ 明白（道理）→ 實踐（生活）」三個教學目的貫穿，程序為開始祈禱 → 引起動機 → 發展 → 綜合 → 生活實踐 → 結束祈禱。
- **三個目標各一節**：一節對一個目標，不合并、不跳過，每節都有可觀察的檢核。
- **引起動機三選一**：每次先給三個不同類型的遊戲，附比較表與建議，教師選定後才寫完整台詞。
- **五次重複**：同一句金句用「聽、說、做、教、記」五種方式出現，讓孩子記得。
- **天主教用語**：天主、聖神、彌撒、亞孟，聖經書名用思高版，不出現簡體字或新教用詞。
- **不編造**：不虛構經文章節、聖人故事、教理條號；不給未經確認的影片網址。

## 安裝

**方法一：當作專案使用**

```sh
git clone <this-repo> sunday-school
cd sunday-school
opencode
```

技能會自動從 `.opencode/skills/` 載入，不用改設定。

**方法二：加到現有專案**

把 `sunday-school-lesson-plan/` 整個資料夾複製到專案的 `.opencode/skills/` 下。

或在 `opencode.json` 加入路徑：

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "skills": ["./path/to/repo/.opencode/skills"],
}
```

## 使用

直接貼三個學習目標：

```
課題：天主看了，樣樣都好
1）讓兒童知道天父創造了天地萬物
2）讓兒童明白天主愛我們
3）鼓勵兒童常懷感恩之心，並善用和欣賞天父的創造
```

或明確呼叫：

```
@sunday-school-lesson-plan <三個目標>
```

技能會先給「引起動機三選一」，你選好之後，它才寫完整教案。

## 檔案結構

```
.opencode/skills/sunday-school-lesson-plan/
├── SKILL.md                     # 技能本體：骨架、時間、規則、檢核表
└── references/
    ├── output-template.md       # 輸出骨架，直接照填
    ├── game-bank.md             # 18 個低材料、不淘汰的遊戲
    └── example-lesson.md        # 完整範例（創世紀 1）
```

## 調整

- 改年齡、時長：直接跟技能說「對象是高小 9-11 歲、90 分鐘」，它會按比例重算時間。
- 改用語：台灣堂區用「阿們」，說一聲就能全篇換。
- 加遊戲：在 `references/game-bank.md` 照格式加一則，技能就會用。

## 說明

教案結構參考天主教香港教區教理中心公開的教案編排方式；聖經採用思高譯本。本 repo 的教案文字與遊戲設計為原創，不含教理中心出版物的內容，引用其教材時請自行留意版權。
