# 範例教案：天主看了，樣樣都好

> 這份範例示範教理中心教案骨架、影片用法、提問層次、五次重複與語氣。實際產出請依教師給的三個目標調整。

## 一、課題

天主看了，樣樣都好

## 二、教學資料

| 項目 | 內容 |
| --- | --- |
| 對象 | 初小 6-8 歲，約 20 人 |
| 時間 | 60 分鐘 |
| 聖經 | 創世紀 1:1-31；2:15（思高版） |
| 教理參考 | 《天主教教理》279-324（創造）；355-373（人為天主肖像） |
| 禮儀節期 | 常年期（可配合 9 月 1 日「為照料受造界祈禱日」） |
| 教材 | 受造物圖卡 15 張、三個圈（貼「天」「地」「海」）、音樂、名牌卡 20 張、粗筆、小球、金句卡每人 1 張 |
| 教具 | 平板或電腦（影片離線檔）、小喇叭、白板筆 |
| 影片 | 創世紀創造動畫，3-4 分鐘，粵語或國語，中文字幕，提前下載 |

## 三、教學目的

1.（認識）讓兒童知道天父創造了天地萬物。
   可觀察行為：能說出至少三樣天主創造的事物，並回答「天主用什麼造？」——「用一句話」。

2.（明白）讓兒童明白天主愛我們。
   可觀察行為：能舉起名牌說「天主愛我」，並用一句話說出理由（「因為我是祂的孩子」）。

3.（實踐）鼓勵兒童常懷感恩之心，並善用和欣賞天父的創造。
   可觀察行為：能說出一件感謝天主的事，並示範一個愛護受造物的動作。

## 五、教學程序

### 5.1 開始祈禱（4 分鐘）

1. 十字聖號：「因父、及子、及聖神之名，亞孟。」
2. 點名：唸到名字的孩子舉手說「天主愛我」。
3. 禱文：
   > 天主，謝謝祢今天讓我們一起來。
   > 求祢打開我們的眼睛，看見祢美好的創造。
   > 亞孟。

### 5.2 引起動機：天主的寶藏在哪裡？（8 分鐘）

> 本節是「引起動機三選一」選定的方案 A（動覺型）。另兩個方案是「天主說——就有了！」（零材料）與「天主造的還是人做的？」（概念型），見 game-bank。

**材料**：受造物圖卡 15 張（太陽、月亮、星星、雲、彩虹、山、樹、花、獅子、小鳥、蝴蝶、魚、鯨魚、蘋果、小孩）、三個圈（貼「天」「地」「海」）、音樂。

**玩法**
1. 圖卡事先藏在教室四周安全、腰部以下的位置，每人至少找得到一張。
2. 音樂響，孩子尋寶；一次只拿一張，拿到時說「這是天主創造的」。
3. 音樂停，把圖卡放進「天／地／海」其中一個圈。
4. 一起檢查；放錯的先不糾正，問「牠住在哪裡？牠需要什麼？」讓孩子自己改。

**教師台詞**
> 今天教室裡藏了很多寶貝。音樂響的時候，去找一張，找到要說：這是天主創造的。
>
> 找到了嗎？想一想，它應該住在天、地，還是海？
>
> 我們總共找到了十五樣！這些寶貝有一個共同的地方——都是天主創造的。
>
> 接下來，我們要看一個影片，看看天主是怎樣一樣一樣造出來的。

**安全與包容**：動作不便或害羞的孩子當「檢查員」，負責看圖卡有沒有放對。

### 5.3 發展（34 分鐘）

#### 5.3.1 認識：天主創造天地（14 分鐘）

**經文**：創世紀 1:1-31——天主說有光，就有了光；造了海、地、日月、魚鳥走獸，最後造了人。

**看前任務（1 分）**
> 看影片的時候，幫我找三樣天主造的東西。看完我要問你：你最想摸哪一樣？

**影片（4 分）**
- 內容：創世紀第一章，六日創造，最後造人
- 長度：3-4 分鐘（超過 5 分鐘只播前半）
- 語言／字幕：粵語或國語，中文字幕
- 播放方式：提前下載，關閉自動播放與廣告
- 搜尋關鍵字：「創世紀 天主創造 兒童 動畫」、「聖經故事 創造 卡通」
- 選擇標準：忠於創世紀 1、沒有恐怖畫面、有字幕、4 分鐘內
- 教師必須先看過一次
- 沒有影片時：6 張圖卡（光／海與陸／日月／魚鳥／走獸／人）、布偶，或白板畫三個畫面

**講述（4 分）**

**畫面一**：一開始什麼都沒有。天主說「有光」，光就出來了。
**動作／聲音**：全班閉眼三秒 → 張開眼、張開手。

**畫面二**：天主分開水，造了海；露出地，長樹長花。天上太陽月亮星星，水裡魚，天上鳥。
**動作／聲音**：手勢比海（波浪）、樹（站直）、魚（游）、鳥（拍翼）。

**畫面三**：最後天主造了人。天主看了這一切，說「樣樣都很好」。
**動作／聲音**：雙手由下往上打開，全班一起說金句。

> 一開始，什麼都沒有。黑黑的，靜靜的。
>
> 天主說：有光！光就出來了。
>
> 天主說：水要聚在一起！海就出現了。
>
> 天主說：地上要長樹、長花！樹就長出來了。
>
> 天主說：水裡要有魚，天上要有鳥！魚就游，鳥就飛。
>
> 最後，天主造了人。就是你，就是我。
>
> 天主看完這一切，說：樣樣都很好。

**提問（4 分）**

| 層次 | 問題 | 想要的答案 |
| --- | --- | --- |
| 事實 | 天主第一天造了什麼？ | 光 |
| 事實 | 天主用什麼造世界？有沒有拿工具？ | 用一句話，沒有工具 |
| 理解 | 天主造完人以後，說了什麼？ | 樣樣都很好 |
| 感受 | 你最想摸哪一樣天主造的東西？為什麼？ | 開放，接受任何答案 |

用動作回答的一題：「喜歡太陽的舉手；喜歡魚的游一下。」讓不愛說話的孩子也能參與。

**重複接力（1 分）**
> 教師：「一開始，天主說——」孩子：「有光！」
> 教師：「天主說：水要聚在一起——」孩子：「就有了海！」
> 教師：「最後天主看了，說——」孩子：「樣樣都很好！」

**檢核**：至少五位孩子能接力說出故事的一句，全班能接「樣樣都很好」。

#### 5.3.2 明白：為什麼最後才造人？（10 分鐘）

**經文**：創世紀 1:26-31——天主照自己的肖像造了人；天主看了祂所造的一切，認為樣樣都很好。

**教學步驟**
1. 生活經驗切入：「如果你要請同學來家裡玩，你會先做什麼？」（先收好玩具、準備好食物）
2. 問「為什麼」：「天主造了魚、鳥、獅子，為什麼最後才造人？」
3. 兩個孩子分享。
4. 教師給出道理：天主先準備好一個家，才接孩子回來。
5. 回到關係：「所以，你不是剛好出現的。天主先為你準備好一切，才造了你。」

**教師台詞**
> 如果你請同學來家裡玩，你會先做什麼？
>
> 先收玩具，先準備好椅子。
>
> 天主也是這樣。祂先造了海給魚，造了樹給鳥，造了草給獅子。
>
> 都準備好了，最後，祂造了人。
>
> 就像爸爸媽媽先把家準備好，才接你回家。
>
> 然後天主看著你，說：樣樣都很好。

**提問**
- 天主造完人以後，說了什麼？
- 你覺得天主為什麼愛你？

**檢核**：請三位孩子各用一句話說出「天主愛我，因為……」，能給出理由即達標。

#### 5.3.3 實踐：謝謝天主，愛護祂的禮物（10 分鐘）

**經文**：創世紀 2:15——天主把人安置在樂園裡，「叫他耕種，看守樂園」。

**教學步驟**
1. 感恩圈：圍圈傳球，拿到球的人說一件感謝天主的事（食物、家人、小狗、下雨、太陽），一人一次。
2. 指著窗外的樹或拿出樂園圖：「天主說：耕種它，看守它。」耕種＝照顧它長大；看守＝不讓它受傷。
3. 三張情境卡，全班一起想辦法：
   - 碗裡還有飯，可是吃不下了。
   - 看到花園裡有一朵很漂亮的花。
   - 洗澡時水一直流。
4. 請三位孩子示範動作：把飯吃完／只聞不摘／把水關掉。
5. 小結，並兩人一組互說一次：「天主看了，樣樣都好，你也是。」

**教師台詞**
> 天主造了這麼多好東西，然後交給我們。
>
> 祂說：耕種，看守。意思就是：照顧它，保護它。
>
> 所以，謝謝天主有兩種方法。一種是用嘴巴說：謝謝天主。
>
> 另一種是用手做：不浪費食物，隨手關燈，輕輕對待小動物。

**提問**
- 做什麼事會讓天主的創造受傷？
- 你可以做哪一件小事，謝謝天主？

**檢核**：每位孩子至少說一件感謝的事，並示範一個愛護的動作。

### 5.4 綜合（6 分鐘）

用三個問題帶孩子複述，對應三節：

| 層面 | 問題 | 誰答 |
| --- | --- | --- |
| 認識 | 天主用什麼造世界？ | 全班齊答「用一句話」 |
| 明白 | 天主為什麼最後才造人？ | 點三位孩子各說一句 |
| 實踐 | 這週你可以為天主的創造做什麼？ | 每人舉手說一件 |

**金句第一次齊唸**：「天主看了，樣樣都好。」（創世紀 1:31）

### 5.5 生活實踐（5 分鐘）

**本週一件行動**
> 這週每天晚上睡前，說一件「謝謝天主」的事，並做一件愛護天主的創造的小事：不浪費食物、隨手關燈，或替一盆植物澆水。下週上課告訴老師你做了什麼。

**派金句卡**：每人一張，帶回家貼在床頭或書桌。

**金句三種唸法**：小聲 → 大聲 → 拍手節奏（天主／看了／樣樣／都好）。

### 5.6 結束祈禱（3 分鐘）

> 天主，謝謝祢造了太陽、海洋、小鳥，還有我。
> 謝謝祢先準備好一切，才造了我。
> 求祢幫助我，這週好好照顧祢送給我們的禮物。
> 因父、及子、及聖神之名，亞孟。

## 六、聖經金句

> 「天主看了，樣樣都好。」（創世紀 1:31）

## 七、喜訊

> 天主造了你，看了，說：很好。

## 八、教學提示

| 狀況 | 應變 |
| --- | --- |
| 沒有合適影片 | 用 6 張圖卡或布偶，教師畫三個畫面；故事不可跳過 |
| 影片播不出來 | 先朗讀創 1:1-5，再用圖卡講述；不現場找網路 |
| 影片太長 | 只播到「造人」為止，其餘用講述補 |
| 時間不夠 | 實踐節的感恩圈改「每人一句」快速輪；情境卡只討論一張 |
| 孩子太興奮 | 舉手閉眼十秒，輕聲說「天主說：安靜」 |
| 人數太少（3-5 人） | 尋寶改「教師藏、孩子找」；感恩圈改一對一 |
| 孩子答不出來 | 縮小問題：「天主造了太陽，還是造了電視？」 |
| 孩子說「天主沒有造恐龍」 | 不辯論：「天主造的東西很多，我們今天只看了其中一些。」 |
| 場地不能跑跳 | 尋寶改「教師出示圖卡，孩子舉手分類」 |

## 九、給家長的訊息

> 今天我們看了創世紀第一章的影片，也讀了創 1:31：天主創造天地萬物，看了認為樣樣都好，並照自己的肖像造了我們。
> 孩子學了金句：「天主看了，樣樣都好。」
> 這週可以問問孩子：天主用什麼造世界？你最喜歡天主創造的哪一樣？也可以陪他睡前說一件感謝天主的事。
